One line roasting a smart fridge that refuses to open after midnight. The fridge's petty rule is the joke: it cards me at the door and decides my leftovers are underage.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, stdlib only) builds the line from three beats — setup, act, turn — validates it against the bounty gate (1–200 characters, one line, names the fridge, the midnight refusal, and the petty rule), and writes it to `/output/entry.txt` with a read-back byte check.
